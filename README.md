# Pocket Eyes

A tiny animated character for **Making tech fun again — episode one**, built for
**Waveshare ESP32-S3-Touch-AMOLED-1.75**: the round 466 × 466 CO5300 AMOLED board.
USB power and a data cable are all you need. No external display wiring or soldering.

**Compiled for this board; not yet physically tested.** Nothing has been uploaded.
Film the factory demo and back it up before the first upload. A verified vendor
recovery image is also downloaded by setup.

## Preview now

Open [preview/index.html](preview/index.html) in Chrome, Safari or Firefox. It works
offline. The eyes wake up, blink, glance around, smile and wink in a repeatable
16-second loop. Use the buttons or `E`, `D`, `R`, `P`; `F` opens clean view and
`Esc` returns. The scrubber pauses at any pose. Amber matches the firmware default;
cyan is also available.

The preview uses drawing commands generated by the actual C++ animation core.
Browser antialiasing, panel color and real refresh timing can differ.

## Setup, build, upload

From this project folder on macOS or Linux, with Python 3 and Git installed:

```sh
python3 tools/project.py setup
python3 tools/project.py build
python3 tools/project.py ports
```

Setup downloads a pinned toolchain and display library into `local/`; it does not
change your global Arduino installation or access the board. The first download
is several gigabytes. On the prepared local workspace, setup and build have
already succeeded.

**Next:** follow [the backup steps](docs/RECOVERY.md), then upload to the actual
port shown on your computer:

```sh
python3 tools/project.py upload --port /dev/cu.YOUR_ACTUAL_PORT
python3 tools/project.py monitor --port /dev/cu.YOUR_ACTUAL_PORT
```

The upload command checks the saved factory backup and builds current source
before flashing. Close the monitor before a later upload. Port names can change
when entering the bootloader. [Detailed setup and Arduino IDE settings](docs/SETUP.md).

## Ready for another take

| Control | Result |
| --- | --- |
| Tap **BOOT**, after the app has started | Restart the eyes reveal |
| Hold **BOOT** for at least 0.8 s, then release | Switch between project demo and eyes |
| Send `e` / `d` in the serial monitor | Start eyes / our moving-square display check |
| Send `r` | Restart current stage |
| Send `p` | Pause/resume a pose |
| Send `c` | Switch amber/cyan |
| Disconnect/reconnect USB, with no battery attached | Boot into the eyes reveal |

Hold BOOT **during power-up** only when you want the bootloader. The **PWR** button
is a power control, not our animation button. The basic project demo is not the
factory firmware; `d` cannot restore the original demo.

## How it works

`Eyes.h` generates deterministic poses and rounded rectangles. `PocketEyes.ino`
handles timing, serial commands and the BOOT button. `Board.h` draws into a
466 × 240 RGB565 buffer in PSRAM, then transfers that center strip to the panel.
The rest stays black. There is no visible clear command between frames. Requested
cadence is one frame per 33 ms; actual smoothness needs a physical test.

Dependencies are fixed in [dependencies.json](dependencies.json): Arduino CLI
1.6.0, Arduino-ESP32 3.3.10, and Waveshare's bundled Arduino_GFX 1.6.4 at an exact
Git revision. Host USB tools have a complete hash-pinned [requirements.lock](requirements.lock).
No Wi-Fi, account, audio, touch, microSD or battery setup is required.

For local checks, install a C++ compiler, `make`, Python 3.9+ and Node 18+:

```sh
make check
make preview
```

The checks cover animation geometry/timing, the preview restart race, and backup
failure cases using a simulated device. They never connect to hardware. CI also
compiles the real ESP32-S3 firmware.
